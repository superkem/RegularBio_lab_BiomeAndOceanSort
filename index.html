Adaptation Match

Every organism is built for its biome. Read each adaptation card and place it in the biome bin where that trait would actually help an organism survive. Place all the cards, then hit Check answers — correct matches turn green, incorrect ones turn red. If anything's wrong, hit Reset and sort again.

Climate Graph Detective

Each graph is one field station's climate record for a year — the orange line is average monthly temperature (left axis), the blue bars are average monthly precipitation (right axis). All ten graphs share the same scale, so you can compare them directly. Use the 3-step method (temperature pattern → rainfall amount → seasonal shape) to pick a biome for every station, then hit Check all answers — correct picks turn green, incorrect ones turn red. If anything's wrong, hit Reset and try again.
